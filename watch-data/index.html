Watch Data Pull

Watch Data Pull is a personal tool with a single user: the owner of the Google Cloud project it runs under.

With the owner's consent, it reads the owner's own smartwatch data from the Google Health API, read-only, once a day. It files a daily summary (sleep, heart rate, steps, exercise and overnight readings) in the owner's private notes, where the owner uses it to plan sleep, exercise and health.

It is not offered to anyone else. It has no sign-up, no other users, no advertising, and it shares no data.
